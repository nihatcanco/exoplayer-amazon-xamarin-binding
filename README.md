# exoplayer-amazon-xamarin-binding
ExoPlayer (v2.10.1) Amazon binding project for Xamarin.

### How To Create aa Nuget Package
- open a command prompt window
- "cd" to the main directory of the solution
- run "nuget pack <NUSPEC_FILE_DIRECTORY>". ex: "nuget pack .\ExoPlayerAmazonXamarinBinding-Core\Xamarin.Amazon.ExoPlayer.Core.nuspec"
